# Пепел Архимага / Ashes of Archmage

Одиночный игровой прототип **0.3.1**: Чертоги Разума, первый облик архимага и объёмный Квас. Сюжета пока нет.

## База

Minecraft Java **26.3**, Forge **66.0.10**, JDK **25** для разработки. Mod ID: `ashes_of_archmage`.

## Что нового

Исправление **0.3.1**: орбита Кваса отодвинута с 1.2 до 1.6 блока. От первого лица скрываются **сама сфера и только её морозный шлейф**; оба вида F5 показывают их. Частицы ледяного импульса по R остаются видимыми и от первого лица. Модель и храм не переделаны.

- Квас — настоящая округлая 3D-модель ледяного шара с трещинами, а не облако частиц. Он вращается возле игрока, оставляя голубую дымку и снежинки.
- Первый облик по направлению референса Инвокера: длинные серебристые волосы с двумя передними прядями, фиолетово-золотая мантия, объёмные плечи, воротник и отдельный плащ. Он включён по умолчанию только для твоего персонажа в одиночном клиенте; **V** переключает обычный скин. Скин аккаунта не меняется. Переключатель пока действует до закрытия клиента.
- Волосы следуют повороту головы, плечи — движениям рук, плащ слегка движется. Шлем скрывает дополнительные волосы; нагрудник скрывает дополнительные части мантии/плаща, чтобы не мешать ванильной броне.
- Освещение Чертогов использует новые атрибуты Minecraft 26.3: храм и герой больше не должны уходить в чёрные силуэты.
- Над центральным алтарём есть подсказка. Для изучения добавлена запасная команда `/archmage learn_test` внутри Чертогов.

## Быстрый тест

1. `/archmage test_start` — открыть Квас и получить нематериальную эссенцию.
2. **F5** — посмотреть героя и шар; **V** — переключить облик.
3. **M** — войти в Чертоги. **ПКМ пустой рукой по центральному аметисту** — изучить импульс. Если не попадаешь: `/archmage learn_test`.
4. **M** — вернуться, **R** — ледяной импульс рядом с мобами: радиус 6 блоков, урон 2, замедление IV на 4 секунды, перезарядка 4 секунды. Задевает и животных, блоки не разрушает.

Заклинание изучается один раз навсегда и назначается в первую ячейку. Повторное изучение не тратит эссенцию. M сохраняет точку/направление возврата. Во время пребывания единственного игрока в Чертогах тики внешних измерений и часы приостанавливаются; Чертоги продолжают работать. LAN и выделенный сервер для этого режима не поддерживаются.

**Подробный сценарий: [docs/playtest-v03.md](docs/playtest-v03.md).** Используй отдельный тестовый мир, не ценное сохранение.

## Установка JAR

1. Выйди из Чертогов, сохрани мир, закрой Minecraft и сделай резервную копию.
2. Удали старый JAR мода (0.3.0, 0.2.0 и более ранние версии) из `mods`.
3. Положи **только один** `ashes-of-archmage-0.3.1.jar` в профиль Minecraft 26.3 / Forge 66.0.10.
4. Для первого теста лучше новый одиночный мир. Команды нашего мода не требуют включения читов.

Формат магического прогресса 0.2 сохранён. Не удаляй мод из мира, пока персонаж находится в его измерении; всё равно делай резервные копии.

## Что ещё не сделано

Сюжет, склеп, народы, NPC, регионы, боссы, остальные сферы, окончательные спеллы, кинематографический вход, экран формул, радиальное меню, смена боевого набора и выбор вариантов причёски. Есть 10 ячеек данных, используется первая. Импульс — служебная проверка, **не финальный Cold Snap из Dota**. Интерфейс крафта будет отдельным этапом.

## Сборка исходников

Открой терминал **внутри `ashes-of-archmage`**, рядом с `build.gradle`. Нужен JDK 25.

Windows:
```bat
gradlew.bat clean test build
gradlew.bat runGameTestServer
```

Linux/macOS:
```sh
chmod +x gradlew
./gradlew clean test build
./gradlew runGameTestServer
```

Клиент разработки: `gradlew.bat runClient` / `./gradlew runClient`. Первая подготовка скачивает Minecraft, библиотеки и ресурсы. `scripts/build-limited-memory.*` снижает настройки памяти, но не гарантирует работу на любом ПК.

## Исходники и ассеты

Обновляй **существующую** папку `ashes-of-archmage` в `hottrip227/mainTOLSTYAK`, не создавай вложенную копию с таким же именем. JAR — для игры, ZIP — для разработки. `.gradle`, `build`, `run`, игровые миры и JDK не загружаются в репозиторий.

Корневой `design.md` репозитория содержит обсуждённый лор; копия внутри проекта старее. Эта версия сюжет не переписывает. Текущее состояние: `dev-status.md`; проверки: `docs/verification-v031.md`.

Модель и текстуры — отдельные редактируемые ассеты. `tools/make_visual_assets.py` пересоздаёт их из параметров; для этой необязательной генерации нужны Python и Pillow. Для обычной Java-сборки Pillow не нужен. `docs/visual-assets/outfit-geometry.json` хранит геометрию костюма. Изображения и модели Valve/Dota в JAR не включены. Документы официального Forge MDK — в `third_party/forge-mdk`.
