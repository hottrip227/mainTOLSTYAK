# Пепел Архимага / Ashes of Archmage

Технический прототип **0.1.0**, не готовый RPG-мод.

## Зафиксированная база

- Minecraft Java **26.3**
- Forge **66.0.10**
- JDK **25**, 64-bit, для разработки
- Gradle Wrapper из официального Forge MDK
- Временный mod ID: `ashes_of_archmage`

## Что здесь есть

- Точка входа Forge; мод должен отображаться в списке модов.
- Справочник десяти сфер.
- Чистая Java-модель прогресса: уровни сфер, баланс эссенций, однократное изучение и ячейки заклинаний.
- Unit-тесты модели. Тестовые формулы не являются дизайном будущих заклинаний.

## Чего пока нет

Нет склепа, NPC, боевых заклинаний, Чертогов Разума, паузы мира или сохранения прогресса в Minecraft. Модель прогресса пока проверяется отдельно от игры.

## Сборка

Открыть терминал в корне проекта.

Windows:
```bat
gradlew.bat clean test build
```

Linux/macOS:
```sh
chmod +x gradlew
./gradlew clean test build
```

При первом запуске Gradle скачивает зависимости. Для запланированных игровых механик потребуется дальнейшая разработка.

## Проверка в игре

Установить Forge 66.0.10 для Minecraft 26.3. После успешной сборки скопировать JAR из `build/libs` в папку `mods` отдельного тестового профиля. В меню Mods должен появиться **Ashes of Archmage**. Проверять на новом мире; ценные сохранения не использовать.

## Загрузка исходников в GitHub

Распаковать архив и загрузить **содержимое папки проекта** в `hottrip227/mainTOLSTYAK`. Не загружать сам ZIP вместо исходников. Каталоги `build`, `.gradle`, `run`, игровые миры и локальный JDK в репозиторий не добавляются.

Лор и концепция находятся в `design.md`; текущее состояние реализации — в `dev-status.md`.

## Проверки этой версии

Полная сборка Forge (`test build`) прошла. Шесть unit-тестов прошли без ошибок. Визуальный запуск Minecraft и проверка мира пока не выполнены: JAR нужно проверить в отдельном игровом профиле.

Первичная подготовка Minecraft для разработки требует много памяти. Если стандартная сборка упирается в память, можно попробовать `scripts/build-limited-memory.bat` (Windows) или `sh scripts/build-limited-memory.sh` (Linux/macOS). Это не гарантия работы на любом компьютере.

Файлы лицензии и журнала официального Forge MDK сохранены в `third_party/forge-mdk`; это не журнал изменений нашего мода. Dota-ассеты в проект не включены.
