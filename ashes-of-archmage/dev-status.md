# Состояние разработки

## Технический этап 0.1.0

Выбрана база Minecraft Java 26.3 + Forge 66.0.10. Проект основан на официальном MDK. Рабочее название и mod ID пока временные.

### Реализовано в исходниках

- Точка входа Forge без игровых механик.
- Десять идентификаторов сфер.
- Независимая от Minecraft модель прогресса и unit-тесты.

### Не реализовано

- Сохранение/загрузка прогресса персонажа.
- Пауза мира при активной симуляции Чертогов.
- Измерение памяти, интерфейсы, склеп, существа, заклинания, генерация регионов.

### Следующий шаг

Связать модель прогресса с игроком/сохранением, проверить сохранение после перезапуска и смерти. Затем сделать минимальный опыт Чертогов и первый игровой тест, не весь мир сразу.

### Нерешённые вопросы

Имена, подробные формулы заклинаний, смерть/возрождение, расходы ресурса и итоговый баланс. Они не нужны для проверки технического каркаса.

## Проверено в этой сборке

- `test build` завершился успешно на JDK 25.
- JUnit: 6 тестов, 0 ошибок, 0 пропусков.
- В JAR есть точка входа, модель прогресса, справочник сфер и `mods.toml`.
- Загрузка Minecraft-клиента и игровой мир пока не проверялись.
- Модель не подключена к сохранению игрока и не проверяет библиотеку реальных формул: это следующий этап, а не готовая магия.
