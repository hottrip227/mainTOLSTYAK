# Проверки исправления 0.3.1

Изменены только орбита/видимость Кваса и способ создания его собственного шлейфа. Модель, сюжет, храм и боевой импульс не переделаны.

- Орбита увеличена с 1.2 до 1.6 блока.
- Клиентский Mixin отключает рендер нашего ItemDisplay от первого лица, определяя сферу по синхронизированному предмету (не по серверным тегам).
- Шлейф теперь создаётся только на клиенте в третьем лице. Отслеживаются именно его частицы: при переходе в первое лицо они удаляются, частицы боевого заклинания не затрагиваются.
- `test build runGameTestServer` прошёл: **12 JUnit + 3 собственных GameTest**, без провалов. XML — `docs/test-results-v031`.
- В настоящем Forge-клиенте 26.3 / 66.0.10 проверены первое лицо до/после F5, вид сзади, вид спереди. В первом лице нет шара и его шлейфа; в обоих третьих видах они есть. Каст R от первого лица показывает снежинки и сообщение результата.
- Снимки этой проверки: `docs/visual-assets/camera-first-after.png`, `camera-third-front.png`, `camera-first-cast.png`.

Тест использовал отдельное локальное QA-сохранение и программный Vulkan-рендер. Пользовательский Windows-профиль, другие моды/шейдеры и длительные сессии не проверены. Старые превью и отчёты 0.3 остаются историческими; они не отражают новый радиус орбиты.

Море облаков и дальние острова пока только направление будущей переработки Чертогов, **в 0.3.1 их нет**. Следующий предложенный этап — понятный GUI изучения, а не сразу новые расы/весь сюжет.
